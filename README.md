

# 🎾 Squash Game

A simple, fun, and interactive squash game built with HTML5, CSS, and JavaScript. The game features a paddle, a bouncing ball, and obstacles. Try to score as many points as possible while avoiding losing the ball. Compete against your own high score!

## Features

* **Paddle Movement**: Control the paddle using the mouse.
* **Ball Movement**: The ball bounces off the walls, paddle, and obstacles.
* **Obstacles**: Randomly placed obstacles that the ball can hit for extra points.
* **High Score**: The highest score is saved in your browser's local storage.
* **Responsive Design**: The game is fully responsive and adapts to different screen sizes.

## Gameplay Instructions

1. Move your mouse left and right to control the paddle.
2. The ball will bounce off the walls and obstacles. Try to keep it in play!
3. Every time the ball hits an obstacle, you earn points.
4. The game ends when the ball falls off the bottom of the screen.
5. After a game over, you can start a new game by clicking the **START** button.

## How to Play

1. Open the game in a web browser.
2. Click the **START** button to begin the game.
3. Move your mouse to control the paddle.
4. Avoid missing the ball, and try to get the highest score possible!

## Technologies Used

* **HTML5**: For the structure of the game.
* **CSS3**: For styling the game interface and elements.
* **JavaScript**: For game logic, ball movement, paddle control, and score tracking.
